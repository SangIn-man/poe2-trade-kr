# PoE Trade Quick Search v2.0

Path of Exile 1과 Path of Exile 2의 **한국 거래소를 하나의 확장 프로그램에서 지원**하는 Chromium 브라우저 확장입니다.

거래소에서 구성한 현재 검색 조건을 저장해 다시 검색하고, PoE1 창고 재산·캐릭터 장비·PoB 비교와 PoE1 지도/PoE2 경로석 정규식 등 보조 도구를 사용할 수 있습니다.

> 이 확장은 개인이 제작한 비공식 커뮤니티 도구입니다. Grinding Gear Games, Kakao Games 및 poe.ninja와 제휴하거나 후원받지 않습니다.

## 주요 기능

| 구분 | 기능 |
|---|---|
| 공통 | PoE1·PoE2 전환, 현재 리그 자동 목록, 현재 거래소 검색 조건 저장, 빌드별 분류, 원클릭 재검색 |
| 필터 | 아이템 속성 자동 파싱, 수치 범위 편집, 필터 활성화/비활성화, 드래그 정렬 |
| Economy | poe.ninja 기반 시세 조회, 한국어 이름과 상세 정보 표시 |
| PoE1 | 창고 재산 계산, 파밍 세션/재산 변동, 현재 리그 캐릭터 장비, PoB 장비 불러오기, 지도 정규식 |
| PoE2 | Expedition 정보, 패시브 트리 검색, 경로석 정규식 |
| PoB 비교 | XML 드래그 앤 드롭, Act1·Act2·Endgame 등 다중 패시브 세트 선택, 노드·숙련 효과 비교 |
| 데이터 | 필터와 설정 JSON 내보내기/가져오기, 오류 로그 확인 및 저장 |

## 설치

Chrome 웹 스토어 등록 전이므로 압축 해제 방식으로 설치합니다.

1. [Releases](https://github.com/SangIn-man/poe2-trade-kr/releases)에서 `poe-trade-quick-v2.0.0.zip`을 다운로드합니다.
2. ZIP의 압축을 원하는 폴더에 해제합니다.
3. Chrome은 `chrome://extensions`, Edge는 `edge://extensions`, Whale은 `whale://extensions`를 엽니다.
4. **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드**를 누릅니다.
6. 압축을 푼 폴더 안의 `manifest.json`이 보이는 폴더를 선택합니다.
7. 열려 있던 한국 거래소 페이지를 새로고침합니다.

## 1분 빠른 시작

1. 확장 설정에서 **게임**과 **리그**를 선택합니다.
2. PoE1 또는 PoE2 한국 거래소에서 아이템 종류, 능력치, 최소·최대 수치 등 원하는 검색 조건을 구성합니다.
3. 검색 폼 아래의 **현재 검색조건 저장**을 누릅니다.
4. 사이드바의 **저장된 필터**에서 **새창** 또는 **현재창**을 눌러 같은 조건으로 다시 검색합니다.
5. 필요하면 필터 이름, 메모, 조건별 사용 여부와 최소·최대 수치를 조정합니다.

검색 결과의 **⭐ 즐겨찾기**는 특정 아이템을 기준으로 필터를 빠르게 만들 때 사용하는 보조 기능입니다. 일반적인 반복 검색은 **현재 검색조건 저장**을 권장합니다.

## 업데이트 전 권장 사항

1. 사이드바 **설정 → 데이터 관리 → 필터 내보내기**로 백업 파일을 저장합니다.
2. 새 릴리스 ZIP을 별도 폴더에 압축 해제합니다.
3. 확장 프로그램 페이지에서 기존 확장의 폴더를 새 폴더로 교체하거나 다시 로드합니다.
4. 확장 프로그램과 열려 있던 거래소 페이지를 모두 새로고침합니다.

기존 필터와 설정은 브라우저의 `chrome.storage.local`에 저장되므로 일반적인 업데이트에서는 유지됩니다. 브라우저 프로필 삭제나 확장 제거에 대비해 중요한 필터는 별도로 내보내 두는 것을 권장합니다.

## 지원 범위

- PoE1 한국 거래소: `poe.game.daum.net`
- PoE2 한국 거래소: `poe.kakaogames.com`
- Chromium 기반 브라우저: Chrome, Edge, Whale
- 글로벌 영문 거래소는 핵심 지원 범위가 아닙니다.

## 개인정보와 외부 데이터

- 필터, 설정, 창고 재산 기록은 브라우저 로컬 저장소에 보관됩니다.
- 확장 프로그램 운영자가 별도의 수집 서버를 운영하거나 사용자 데이터를 수집하지 않습니다.
- 거래소 기능은 한국 거래소/Path of Exile API에, 시세 기능은 poe.ninja에 직접 요청합니다.

## 브라우저 권한 안내

- 이 확장은 사이드바를 페이지 안에 표시하고 **다른 페이지 허용** 옵션을 제공하기 위해 모든 URL에 콘텐츠 스크립트를 등록합니다.
- 기본 핵심 기능은 한국 PoE1·PoE2 거래소에서 사용하며, 다른 페이지에서의 사이드바 유지는 설정에서 끌 수 있습니다.
- `file://` 페이지에서 사용하려면 브라우저 확장 설정의 **파일 URL에 대한 액세스 허용**을 사용자가 별도로 켜야 합니다.
- 확장 운영자가 방문 기록이나 페이지 내용을 수집하는 별도 서버는 없습니다.

## 문제 해결

- 사이드바가 보이지 않으면 확장 프로그램과 거래소 페이지를 모두 새로고침하세요.
- 게임을 바꾼 뒤 리그가 맞지 않으면 설정의 리그 새로고침 버튼을 누르세요.
- PoE1 계정 기능은 한국 PoE 사이트 로그인 상태와 계정 공개 범위의 영향을 받을 수 있습니다.
- 오류가 반복되면 **설정 → 데이터 관리 → 최근 에러 보기**에서 로그를 확인하세요.
